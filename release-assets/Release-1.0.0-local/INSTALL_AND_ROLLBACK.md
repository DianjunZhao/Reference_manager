# LatticeLens 1.0.0 — same-Mac local artifact

This DMG contains the current refresh-progress regression build. It is ad-hoc
signed for local inspection only; it is not Developer ID signed or notarized.

Install by dragging `LatticeLens.app` to `/Applications`. The DMG smoke test
uses a project-local fixture copy and never writes to `/Applications` or a user
library. Uninstall removes only the app bundle; keep the library and PDFs.
